**Your resume is not in this file.** `resume.pdf` is sent to the model directly as a
document on every call, so it stays the single source of truth — edit the PDF and both
scoring and answers pick it up with no transcription step and nothing to keep in sync.

This file is only for the things a resume doesn't contain: how you write, what you'll
refuse, and the detail behind the bullet points. Keep it concrete — the model is
instructed to skip rather than invent, so what's missing here becomes a red field you
fill by hand, not a fabricated answer.
